使用说明

重要提示

发票识别说明：本工具使用PDF文本提取技术，识别成功率并非100%，请核对识别结果。如果发票是扫描件或图片格式的PDF，文本信息可能无法准确提取。建议使用电子发票原件（含可选中文字的PDF）以获得最佳识别效果。

合并功能：即使无法识别发票信息，仍可正常合并PDF文件为A4双联格式，方便打印。

内容缺失处理：某些特殊情况下发票内容可能会出现缺失，可尝试将PDF转换成扫描型PDF（即图片型PDF）后，再用本工具合并发票即可解决。

离线使用：若想在无网络环境下使用，请在 GitHub 仓库 下载全部源码，打开 index.html 即可使用。
